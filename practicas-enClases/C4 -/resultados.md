# Resultados experimentales - C4

Equipo utilizado: completar (procesador, RAM y sistema operativo).

Comando ejecutado:

```bash
dotnet run -c Release
```

Protocolo:
- 1 corrida de calentamiento por algoritmo.
- 3 corridas medidas por algoritmo.
- Promedio aritmético de las tres corridas.

Completar con los valores que produzca la ejecución local:

| Algoritmo | Promedio (ms) |
|---|---:|
| Búsqueda lineal | |
| Búsqueda binaria | |
| Cociente lineal / binaria | |

Interpretación: un cociente mayor que 1 indica que la búsqueda lineal tardó más que la binaria. Los tiempos pueden variar entre equipos; por eso se registran los resultados obtenidos localmente.
